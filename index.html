Ajudante de passphrase

Digite o que conseguir ler. O que você escreveu é lei: maiúscula não vira minúscula no Tab nem no Copiar. Sem opção na lista, corrige typo de 1–2 letras e pinta o seu case. Nada é enviado, gravado ou medido.

      Como usar e o que esta página não faz
      
      
        
    • Não existe servidor nem banco: words.js já traz as listas. Depois do carregamento a página não faz pedido de rede.
      • 
        
    • O que você digitou é lei: Tab não passa a palavra para minúsculas. Só acrescenta o resto, no mesmo padrão de case.
      • 
        
    • Se não houver opção na lista, a busca por typo (1–2 letras, inclusive letras trocadas) sugere a palavra certa e o Tab aplica o seu case nela.
      • 
        
    • A saída padrão é como digitado. Copiar cola exatamente o texto da saída, com as maiúsculas. CamelCase e os outros formatos só mudam a cópia se você escolher — e a página avisa se o formato for destruir o case.
      • 
        
    • Shift+Tab desfaz a última completação. Espaço aceita um prefixo único (3 letras na EFF Large). Tab sem sugestão não prende o teclado.
      • 
        
    • O padrão da lista é a EFF Large. As 3 primeiras letras já identificam cada palavra.
      • 
        
    • Se uma palavra só existe numa lista (ex.: ritalin → EFF Large), a página avisa e você pode filtrar só nela.
      • 
        
    • A passphrase vive só na memória desta aba. Sem cookies, localStorage ou analytics.
      • 
        
    • O conversor Segredo ↔ palavras usa a lista BIP-39 com prefixo único de 4 letras e checksum: segredos de até 28 bytes viram 12–24 palavras, e uma palavra trocada na transcrição é acusada na volta. A conversão é matemática local — nada é enviado.
      • 
        
    • GitHub Pages só entrega os arquivos. Para zero rastro de IP, baixe a pasta e abra o index.html offline.
