      Como usar e o que esta página não faz
      
      
        
    • Não existe servidor nem banco: words.js já traz as listas. Depois do carregamento a página não faz pedido de rede.
      • 
        
    • O que você digitou é lei: Tab não passa a palavra para minúsculas. Só acrescenta o resto, no mesmo padrão de case.
      • 
        
    • Se não houver opção na lista, a busca por typo (1–2 letras, inclusive letras trocadas) sugere a palavra certa e o Tab aplica o seu case nela.
      • 
        
    • A saída padrão é como digitado. CamelCase e os outros formatos só mudam a cópia se você escolher.
      • 
        
    • O padrão da lista é a EFF Large. As 3 primeiras letras já identificam cada palavra.
      • 
        
    • Se uma palavra só existe numa lista (ex.: ritalin → EFF Large), a página avisa e você pode filtrar só nela.
      • 
        
    • A passphrase vive só na memória desta aba. Sem cookies, localStorage ou analytics.
      • 
        
    • GitHub Pages só entrega os arquivos. Para zero rastro de IP, baixe a pasta e abra o index.html offline.
